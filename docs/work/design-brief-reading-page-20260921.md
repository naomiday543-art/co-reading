## PROMPT（以下整段貼給 Claude Design）

你要幫我打磨一個既有桌面 Web App 的**單一頁面版面**：Co-Reading（AI 論文共讀）的「論文閱讀頁」。這不是重新設計——品牌、配色、字體、功能全部沿用，我要的是**把垂直空間擠出來、把層級理清楚**。

### 這一頁是什麼、誰在用
一位科研使用者在筆電上長時間使用：左邊讀論文 PDF，右邊跟 AI 討論這篇論文。論文多半是**雙欄排版的英文期刊文章**，在半個螢幕寬的框裡必須放大到 150–170% 才看得清楚，所以她同時需要上下與左右移動頁面。她的可用視窗大約 **1300–1450 × 650–800 px**（瀏覽器縮放偏大、視窗不高）。**這一頁最貴的資源是垂直高度**，其次是左欄寬度。

### 現在的結構（由上到下，括號內是目前高度）
1. **全域頂欄**（約 48px）：左側漢堡鈕＋Logo「Co-Reading 共讀」，右側 深色模式／全螢幕／設定 三顆圖示鈕。
2. **論文標題列**（約 44px）：`‹ 返回列表`、`[閱讀模式]` 膠囊鈕、論文標題（serif、單行截斷）、閱讀狀態下拉（「閱讀中 ▾」）、右端一顆關閉 ✕。
3. **左右分欄**（中間一條可拖曳的分隔線，左欄預設 58%）：
   - **左欄**
     - 分頁列（約 38px）：左邊兩顆分頁 `AI 摘要`｜`原文 · SI 1`（底線式 tab，選中為強調色）；**同一行右側**是膠囊切換組 `[正文｜SI 1｜SI 2…]`、一顆 `＋`（加補充文件）、膠囊切換組 `[PDF 原檔｜文字版]`。
     - 選到某份 SI 時，分頁列下面多一行小工具列（約 24px，11.5px 字）：`檔名　16,680 字　☑ AI 讀得到　改名　刪除這份`。
     - **PDF 框**：瀏覽器內建 PDF 檢視器的 iframe，圓角 8px、1px 邊框。它**自帶一條約 56px 高的深色工具列**（頁碼、縮放、旋轉、註記、下載…）以及自己的上下／左右捲軸。
   - **右欄（討論）**
     - 標題行：圖示＋「討論」。
     - meta 行（11.5px 淡色）：`✦ 精煉本次共讀`　`[✓ 已帶上]` 小膠囊　`研究續窗 · 方向:py-GCMS`。
     - 訊息列表：白色圓角卡片內的長篇 AI 回覆（段落、粗體、條列），卡片底部有 `↻ 重新生成`　`存為洞察` 兩顆淡色文字鈕；使用者訊息是靠右的淡橘色泡泡。
     - 輸入區：多行輸入框（圓角 12px）＋右側一顆強調色「送出」大鈕。
     - 輸入框下面兩行淡色小字鈕：`貼上原文提問`；`Aa 小`　`提取洞察`。
4. **底部上傳細條**（28px＋7px 邊距）：虛線框單行——圖示、`將 PDF 拖拽到此處上傳，或 點擊選擇文件 · 支援批次匯入`、`這篇屬於：[下拉]`。

### 硬約束（請不要違反）
- **PDF 框內部完全不可控**：那是瀏覽器的檢視器，工具列、捲軸、縮放 UI 都改不了、也不能蓋東西上去。原型裡請用一個灰色佔位框表示，框頂畫一條 56px 深色假工具列、框底與右側各畫一條假捲軸，**其餘留白**。你能設計的只有框的外面。
- **不准新增任何整排的控制列**。新東西一律併進既有的某一行，或做成點開才出現。
- **所有現有功能都要保留且找得到**（上面列到的每一顆按鈕）。可以換位置、收進選單、改成圖示＋tooltip，但不能消失。
- 沿用下面的設計 token 與字體，**不改配色、不換字體、不加漸層與陰影特效**。亮色與深色兩套都要成立。
- UI 文案一律**繁體中文**，第二人稱用「你」。
- 左欄寬度在 480–900px 之間都要成立；分頁列右側那組切換在左欄很窄時會整塊折到分頁上方一行（兩行），這個行為保留。

### 我想請你解的問題（依優先序）
1. **頂部三層太厚**：全域頂欄＋論文標題列＋分頁列合計約 130px，PDF 還沒開始。請提出把它壓到 **≤ 90px** 的方案（例如：閱讀頁時把全域頂欄與標題列併成一行；標題列的返回／閱讀模式／狀態怎麼收）。請給 2 個方案並說明取捨。
2. **左右兩欄的底邊與節奏**：左欄 PDF 框底、右欄輸入區底、底部上傳細條，三者現在沒有對齊關係。請定一套底部節奏（兩欄底邊對齊在同一條線、與上傳細條的間距一致）。
3. **右欄頭尾的密度**：頂部「討論」標題行＋meta 行是兩行；底部輸入框下面又是兩行小字鈕。請重新安排層級，目標是右欄頭尾合計**少一行以上**，而且「精煉本次共讀」「提取洞察」這兩個重要動作不能變得更難找。
4. **上傳細條在這一頁的存在感**：在閱讀頁它是次要動作。請評估兩種做法並各出一版：(a) 保留 28px 細條但更安靜；(b) 平時收成右下角一顆小鈕，**只有拖檔案進視窗時**才展開成全寬的拖放區。
5. **選到 SI 時那一行小工具列**：能不能不佔一整行（例如收進 `SI 1` 膠囊旁的「⋯」選單，或變成膠囊的 hover／選中狀態的延伸），同時「AI 讀得到」這個開關的狀態要一眼看得出來。
6. **分隔線**：現在是 6px 寬的淡色直條，中間有一段 40px 的深色握把；hover 變強調色，可拖曳、雙擊還原。請確認它夠不夠明顯，不夠的話怎麼加強而不搶戲。

### 交付
- **一個可互動的 HTML 原型**（單檔、無外部依賴除了字體），用我給的 CSS 變數，能切換亮／深色，能切換「正文／SI 選中」「PDF／文字版」兩個狀態。
- 兩個畫板尺寸：**1440×800** 與 **1300×660**。
- 一張**高度預算表**：每個區塊 before → after 各幾 px，最後算出 PDF 框在 1300×660 下能拿到多高（現在約 463px）。
- 一份**變更清單**：改了什麼、**刻意沒改什麼**、每個被搬動的按鈕現在在哪。
- 問題 1 與 4 各給兩個方案；其餘給一個你最推薦的。
- 不要做：新功能、新頁面、Logo／品牌調整、插畫、動效展示、行動版。
